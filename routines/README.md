# Routine-creation prompts

Routines cannot be created through the gateway; each file here holds the exact text to paste into the owning Bot's chat (or its Routines panel) once per Bot, and again after a rotation. Every routine has: an owner, a schedule with timezone, a "no data" clause (write heartbeat, stop), a step cap, and a one-line chat summary so silent completions are visible.

Cadence tiers: **Lean** (start here, 7 days) → **Standard**. Never schedule below 15 minutes; the queue lag is 10–37 min anyway.
